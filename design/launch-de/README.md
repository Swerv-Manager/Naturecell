# Lancering af naturecell.de: grundpris (Grundpreis)

Tysk lov (PAngV) kræver pris pr. 100 ml ved siden af prisen. Temaet viser den automatisk
på alle sprog undtagen dansk, når varianten har mængdedata (indstillingen
"Vis grundpris også på dansk" er slået fra).

Mængdedata er IKKE sat endnu, fordi det nuværende live-tema (208647848274) viser grundpris
med det samme på naturecell.dk. Kør derfor mutationen i `grundpreis-mutation.json`
(Shopify Admin GraphQL, productVariantsBulkUpdate) samme dag som det nye tema publiceres.

Undtaget: varer på 10 ml eller derunder (CBD-olier 10 ml, Lip Balm 6 ml), sæt med
forskellige produkter, gavekort og handske.
